## Featured Projects

| [**sota-radar**](https://github.com/sandr-flow/sota-radar) | AI-powered Telegram bot that tracks arXiv and Hugging Face Daily Papers, generates bilingual summaries, and supports deeper RAG-based paper analysis. | Python, Aiogram, SQLAlchemy, SQLite, ChromaDB, Mistral |
| [**Dynamic Semantic Window RAG**](https://github.com/sandr-flow/rag-dynamic-semantic-window) | Experimental RAG retrieval strategy that expands context windows dynamically after retrieval using semantic similarity, query relevance, and benchmark-driven evaluation. | Python, RAG, Embeddings, Benchmarking |

| [**Digital Genesis**](https://github.com/sandr-flow/digital-genesis) | Experimental asynchronous RAG architecture with graph-based long-term memory and self-reflection loops for a local single-user setup. | Python, NetworkX, ChromaDB |

| [**Storyline AI Bridge**](https://github.com/sandr-flow/storyline-ai-bridge) | JavaScript bridge enabling LLM integration inside legacy LMS flows built with Articulate Storyline, bypassing CORS and iframe limitations. | JavaScript, LMS Integration, RPC |
| [**Query Optimizer**](https://github.com/sandr-flow/query-optimizer) | Prototype exploring Multi-Query Retrieval with Grok API and FAISS to test query expansion logic. | Python, FAISS, LLM API |

## Highlights

- **Game localization tooling**: built a full AI-assisted translation pipeline for NWN modules, including web UI, glossary generation, contextual translation, and binary-safe reinjection.
- **Research automation**: shipped an MVP Telegram assistant for AI/ML paper discovery, bilingual summarization, trending-paper digests, and RAG-based deep analysis.
- **Retrieval experiments**: benchmarked dynamic semantic context expansion against fixed windows and semantic splitters across Wikipedia and QASPER datasets.
- **LLM integrations**: connected AI workflows to Telegram, LMS environments, document pipelines, vector stores, and OpenAI-compatible providers.
